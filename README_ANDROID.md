# LitQuest Story Mode — consolidated project

This ZIP is a single, ready-to-upload source project for the fresh `LitQuest_StoryMode` GitHub repository.

## Included

- Existing British Literature module and question bank.
- Indian Literature in English module and its 95 MCQs.
- New Zealand Literature syllabus: five units and all 15 prescribed texts.
- 315 New Zealand Literature MCQs: 20 per text, with 25 each for *The Whale Rider*, “Politics and Maori Literature” and *The End of the Golden Weather*.
- Separate New Zealand hub options for syllabus, all questions, unit-wise practice, text-wise practice, Story Mode, performance and leaderboard.
- Linear *The Whale Rider* Story Mode with all 21 numbered chapters, character/theme/craft/exam notes and sequential progress.
- The final-section marker “The Girl from the Sea” before Chapters Twenty and Twenty-one, matching the supplied edition's structure.
- Original generated background artwork and locally packaged ambience/effects.
- Capacitor configuration and GitHub Actions Android APK workflow.

## Upload to GitHub

1. Extract this ZIP directly into the local `LitQuest_StoryMode` repository folder.
2. Choose **Replace the files in the destination** if Windows asks.
3. Do not delete the hidden `.git` folder. This ZIP intentionally does not contain `.git`.
4. Confirm `.github/workflows/android-apk.yml` is in the repository root.
5. In GitHub Desktop, review Changes, commit, then Push origin.
6. Open GitHub Actions and download `LitQuest-Android-APK` from the newest successful run.

## Build

The workflow installs Node dependencies, runs `npm run build`, adds/syncs the Capacitor Android platform, and builds a debug APK. `www/` is generated by `build.js`; it is intentionally not included as a duplicate source tree.

## Local browser preview

With Node.js installed, run:

```bash
npx --yes http-server . -p 5501 -c-1
```

Then open `http://localhost:5501`.

## Important scope and study notes

Story Mode is a linear paraphrased study companion, not a reproduction of the novel. It does not branch into alternate events or endings. The 315 MCQs are original practice material, not official past papers or exam predictions. Check close-reading details against the prescribed edition and lecturer notes.

Progress and leaderboard records are stored locally on each device; they are not synchronised between phones. No database, AI API or account system is required.
