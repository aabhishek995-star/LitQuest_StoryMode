# LitQuest Story Mode — consolidated project

This ZIP is a consolidated project for the fresh `LitQuest_StoryMode` GitHub repository.

## Included
- Existing British Literature module and its question bank
- Indian Literature in English module and 95 syllabus-based MCQs
- New Zealand Literature subject card and The Whale Rider Story Mode prototype
- Chapter 1 playable story scenes, study tabs, three knowledge-check questions, local progress
- Original generated backgrounds and locally packaged audio effects
- Capacitor configuration and GitHub Actions Android APK workflow

## Important scope note
The Whale Rider hub lists all 21 chapters, but only the opening chapter is playable in this prototype. Later chapters are explicitly marked upcoming. This is not yet the complete 21-chapter adaptation.

## Upload to GitHub
1. Extract this ZIP directly into the local `LitQuest_StoryMode` repository folder.
2. If Windows asks, choose to replace files in the destination.
3. Do not delete the hidden `.git` folder in the destination. This ZIP intentionally does not contain `.git`.
4. Confirm that `.github/workflows/android-apk.yml` exists in the repository root.
5. In GitHub Desktop, review Changes, commit, then Push origin.
6. Open GitHub Actions and download `LitQuest-Android-APK` from the newest successful run.

## Build
The workflow installs Node dependencies, runs `npm run build`, adds/syncs the Capacitor Android platform, and builds a debug APK. `www/` is generated by `build.js`; it is intentionally not included as a duplicate source tree.

## Local browser preview
With Node.js installed, run `npx --yes http-server . -p 5501 -c-1` from this folder and open `http://localhost:5501`.

Progress is stored locally on each device. It is not synchronised between phones.
